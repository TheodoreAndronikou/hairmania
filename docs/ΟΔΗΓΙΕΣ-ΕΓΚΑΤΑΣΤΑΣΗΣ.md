# Οδηγίες εγκατάστασης — HAIR MANIA VALKANIS

Χρόνος: **~20 λεπτά**, μία φορά. Χρειάζεσαι έναν λογαριασμό Google.

Μέχρι να ολοκληρώσεις το Μέρος Β, το site τρέχει σε **DEMO MODE**: δείχνει
ψεύτικες ώρες και μια κόκκινη ταινία στην κορυφή. Είναι απολύτως λειτουργικό
για να το δείξεις στον ιδιοκτήτη.

---

## ΜΕΡΟΣ Α — Ανέβασμα του site στο GitHub Pages (5΄)

1. Φτιάξε νέο repository στο GitHub, π.χ. `hairmania`, **Public**.
2. Ανέβασε **τα περιεχόμενα του φακέλου `site/`** στη ρίζα του repo.
   (Δηλαδή το `index.html` πρέπει να είναι στη ρίζα, όχι μέσα σε `site/`.)
   - Από browser: *Add file → Upload files* και σύρε μέσα όλα τα αρχεία.
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**
4. Μετά από 1–2 λεπτά το site είναι ζωντανό στο
   `https://<το-username-σου>.github.io/hairmania/`

---

## ΜΕΡΟΣ Β — Το booking backend (15΄)

### Β1. Φτιάξε το Google Sheet

1. Πήγαινε στο <https://sheets.new> και ονόμασέ το **HAIR MANIA — Ραντεβού**.
2. Μενού **Επεκτάσεις → Apps Script**.
3. Σβήσε ό,τι υπάρχει στο `Code.gs` και **επικόλλησε ολόκληρο** το περιεχόμενο
   του αρχείου `apps-script/Code.gs`.
4. Στην κορυφή του κώδικα άλλαξε μόνο αυτή τη γραμμή:

   ```js
   var SITE_URL = 'https://TO-USERNAME-SOU.github.io/hairmania/';
   ```

5. Πάτα το εικονίδιο ⚙️ (**Ρυθμίσεις έργου**) στα αριστερά και βεβαιώσου ότι
   η **ζώνη ώρας** είναι `(GMT+02:00) Athens`.
6. Αποθήκευσε (💾).

### Β2. Τρέξε το `setup()`

1. Στη λίστα συναρτήσεων πάνω-πάνω διάλεξε **`setup`** και πάτα **Εκτέλεση**.
2. Θα σου ζητήσει άδειες: **Review permissions → διάλεξε τον λογαριασμό →
   Advanced → Go to … (unsafe) → Allow.**
   *(Το «unsafe» είναι το κανονικό μήνυμα της Google για script που δεν έχει
   περάσει από δημόσιο έλεγχο — είναι δικό σου script στον δικό σου λογαριασμό.)*
3. Γύρνα στο Sheet: θα έχουν δημιουργηθεί τρία φύλλα — **Ωράριο**, **Υπηρεσίες**,
   **Ραντεβού** — ήδη συμπληρωμένα με το σωστό ωράριο και τις τιμές.

### Β3. Δημοσίευσε το Web App

1. Πάνω δεξιά **Ανάπτυξη → Νέα ανάπτυξη**.
2. Τύπος (γρανάζι) → **Εφαρμογή web**.
3. Ρυθμίσεις:
   - **Εκτέλεση ως:** *Εγώ* (ο λογαριασμός σου)
   - **Ποιος έχει πρόσβαση:** **Οποιοσδήποτε** ← κρίσιμο, αλλιώς δεν θα
     μπορούν οι πελάτες να δουν διαθεσιμότητα
4. **Ανάπτυξη** → αντίγραψε το **URL της εφαρμογής web**
   (μοιάζει με `https://script.google.com/macros/s/AKfy…/exec`).

### Β4. Σύνδεσε το site

Άνοιξε στο repo το αρχείο `assets/js/config.js`, βρες την πρώτη γραμμή
ρύθμισης και βάλε το URL:

```js
API_URL: 'https://script.google.com/macros/s/AKfy…/exec',
```

Αποθήκευσε. Σε ~1 λεπτό η κόκκινη ταινία DEMO εξαφανίζεται και το site
δείχνει πραγματικές ώρες.

> **Έλεγχος:** άνοιξε στον browser το `…/exec?action=ping`. Πρέπει να δεις
> κάτι σαν `{"ok":true,"tz":"Europe/Athens",...}`.

### Β5. (Προαιρετικό) Gallery από Google Drive

1. Φτιάξε φάκελο στο Drive, π.χ. **HAIR MANIA — Φωτογραφίες**.
2. Δεξί κλικ → **Κοινή χρήση → Οποιοσδήποτε με τον σύνδεσμο → Προβολέας**.
3. Άνοιξε τον φάκελο· στο URL μετά το `/folders/` είναι το ID. Αντίγραψέ το.
4. Στο Apps Script βάλε το στη γραμμή
   `var GALLERY_FOLDER_ID = 'ΕΔΩ_ΤΟ_ID';` και κάνε **Ανάπτυξη → Διαχείριση
   αναπτύξεων → ✏️ → Έκδοση: Νέα έκδοση → Ανάπτυξη**.

Από εκεί και πέρα ο ιδιοκτήτης ανεβάζει φωτογραφίες στον φάκελο από το
κινητό του και εμφανίζονται στο site.

### Β6. (Προαιρετικό) Ξεχωριστό ημερολόγιο

Αν δεν θέλεις τα ραντεβού μπλεγμένα με τα προσωπικά:
Google Calendar → **Άλλα ημερολόγια +** → *Δημιουργία νέου ημερολογίου* →
όνομα «Ραντεβού Κουρείου» → Ρυθμίσεις ημερολογίου → **Αναγνωριστικό
ημερολογίου** → αντίγραψέ το στη γραμμή `var CALENDAR_ID = '…';` και κάνε
νέα ανάπτυξη (όπως στο Β5.4).

## ⚠️ Κάθε φορά που αλλάζεις τον κώδικα του Apps Script

Δεν αρκεί η αποθήκευση. Πρέπει:
**Ανάπτυξη → Διαχείριση αναπτύξεων → ✏️ (μολύβι) → Έκδοση: «Νέα έκδοση» → Ανάπτυξη.**
Το URL παραμένει το ίδιο.

## Επίλυση προβλημάτων

| Σύμπτωμα | Αιτία / λύση |
|---|---|
| Το site δείχνει «Δεν μπορέσαμε να φορτώσουμε τις ώρες» | Το `API_URL` λείπει ή είναι λάθος· ή η ανάπτυξη δεν είναι «Οποιοσδήποτε». |
| Όλες οι μέρες γκρι | Το φύλλο **Ωράριο** είναι άδειο ή τα ονόματα ημερών δεν είναι ακριβώς «Δευτέρα, Τρίτη, …». |
| Οι ώρες είναι μετατοπισμένες | Λάθος ζώνη ώρας στο Apps Script (Β1.5) ή στο Sheet. |
| Δεν έρχονται email | Το δωρεάν όριο Gmail είναι 100 email/ημέρα. Επίσης έλεγξε τα Ανεπιθύμητα. |
| Οι φωτογραφίες Drive δεν φαίνονται | Ο φάκελος δεν είναι κοινόχρηστος «Οποιοσδήποτε με τον σύνδεσμο». |
