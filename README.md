# HAIR MANIA — σύστημα online ραντεβού για κουρείο

Mobile-first στατικό site με πλήρες σύστημα κρατήσεων και διαχειριστικό
για τον ιδιοκτήτη. Ελληνικά / Αγγλικά. Χτίστηκε για το HAIR MANIA VALKANIS
στα Γιαννιτσά· είναι πρότυπο, ώστε ένα νέο κατάστημα να στήνεται από το
ίδιο project.

**Ζωντανά:** https://theodoreandronikou.github.io/hairmania/

## Αρχιτεκτονική

```
Πελάτης / ιδιοκτήτης (browser)
   │  HTTPS — μόνο κλήσεις συναρτήσεων (RPC), ποτέ πίνακες απευθείας
   ▼
Supabase — PostgreSQL
   ├── πίνακες κλειδωμένοι: RLS ενεργό, καμία πολιτική
   ├── συναρτήσεις security definer: availability, book, cancel, admin_*
   │     (ο ρόλος anon καλεί ΜΟΝΟ όσες του δίνονται ρητά)
   ├── exclusion constraint: η βάση αρνείται επικαλυπτόμενα ραντεβού
   └── pg_net → Resend: email κράτησης και ακύρωσης
         (προς πελάτες χρειάζεται δικό μας domain — σήμερα ανενεργά)

Στατικά αρχεία (HTML/CSS/JS, χωρίς build) ──► GitHub Pages
cron-job.org ──► ωριαίος έλεγχος βάσης και site, ειδοποίηση αν πέσουν
```

### Πώς αποφεύγεται το διπλοκλείσιμο

Το frontend δεν αποφασίζει ποτέ. Ο πίνακας `appointments` έχει περιορισμό
`exclude using gist (tstzrange(starts_at, ends_at) with &&)` για τα ενεργά
ραντεβού: η ίδια η βάση αδυνατεί να αποθηκεύσει δύο που επικαλύπτονται.
Αν δύο πελάτες πατήσουν την ίδια ώρα, ο ένας περνάει και ο άλλος παίρνει
`SLOT_TAKEN` και του ζητείται νέα ώρα.

### Ακύρωση από τον πελάτη

Κάθε κράτηση παίρνει τυχαίο κωδικό ακύρωσης. Ο πελάτης παίρνει σύνδεσμο
`akyrosi.html?id=…&k=…` στην οθόνη επιβεβαίωσης και μέσα στο `.ics` — και
στο email, όταν ενεργοποιηθούν τα email προς πελάτες. Η βάση επιτρέπει ακύρωση έως **2 ώρες πριν** — πιο κοντά απαντά
`TOO_LATE`.

### Αρχείο .ics

Παράγεται στον browser, ώρες σε **UTC** (καμία εξάρτηση από VTIMEZONE), με
δύο υπενθυμίσεις (−2 ώρες, −30 λεπτά). Ανοίγει σε Google, Apple, Samsung,
Outlook.

## Θέματα εμφάνισης

Τρία πλήρη θέματα ζουν μαζί. Αλλάζεις με μία λέξη στο
`site/assets/js/config.js`:

```js
theme: 'c',   // 'c' Ticket (ενεργό) | 'a' Editorial | 'b' Warm Analog
```

Για σύγκριση χωρίς αλλαγή αρχείου: `?theme=a`, `?theme=b`, `?theme=c` στο URL.

**Γραμματοσειρές — προσοχή:** κάθε γραμματοσειρά είναι ελεγμένη ότι έχει
ελληνικούς χαρακτήρες. Πολλές δημοφιλείς (Archivo, Space Grotesk, Instrument
Sans, DM Mono, Bricolage Grotesque, Anton, Oswald) **δεν έχουν** — τα
ελληνικά πέφτουν σε fallback και το site δείχνει σπασμένο.

**Κεφαλαία:** τα ελληνικά κεφαλαία δεν παίρνουν τόνο (ΔΙΑΛΕΞΕ ΩΡΑ, όχι
ΔΙΆΛΕΞΕ ΩΡΑ). Δεν το αφήνουμε στον browser — το επιβάλλει η
`fixGreekCaps()` στο `app.js`.

## Λειτουργία επίδειξης

Αν τα στοιχεία `SUPABASE` στο `config.js` είναι κενά, η σελίδα κράτησης
δείχνει ψεύτικες ώρες με ταινία «DEMO» στην κορυφή και δεν κλείνει τίποτα.
Το διαχειριστικό δεν λειτουργεί χωρίς βάση.

Στον φάκελο `docs/`:

| `ΠΑΡΑΔΟΣΗ.md` | προγραμματιστή που παραλαμβάνει το έργο — αρχείο, βάση, ασφάλεια, τι κάνω όταν σπάσει |
| `ΟΔΗΓΙΕΣ-ΕΓΚΑΤΑΣΤΑΣΗΣ.md` | στήσιμο από το μηδέν, και για νέο κατάστημα |
| `ΟΔΗΓΟΣ-ΙΔΙΟΚΤΗΤΗ.md` | τον κουρέα — χωρίς τεχνικούς όρους |
| `ΚΟΣΤΟΛΟΓΙΟ.md` | τι κοστίζει τι, και σενάρια |

## Τοπική προεπισκόπηση

```bash
node serve.js
```

Ανοίγει στο `http://localhost:5178` και μιλάει με την πραγματική βάση.
